# 한동대생 장소 은어 목록

한동대 학생들이 실제로 쓰는 장소 줄임말/은어. `POPULAR_ORIGINS`/`POPULAR_DESTS`(app.js)나
장소 자동완성 별칭 매핑에 나중에 쓸 참고 자료 — 카카오 자동완성으로는 이런 은어가 안 잡히니까,
실제 주소/좌표를 하나씩 확인한 뒤 `PLACE_COORDS`에 별칭으로 추가하는 작업이 남아있다.

수집일: 2026-09-16

## 학교(캠퍼스 내)
뉴턴, 언어교육원, 오흡, 비벤, 오석, (한동대)택정, 느햄, 현동, 버정, 팔각정

## 원룸촌(자취촌)
그할마, 유야, 야멍, 궁물촌, 예성, 양덕, 맛깨비(토시래), 고기왕, 금강산돌구이, 다이소, 유야

## 다음 할 일
각 은어가 정확히 어떤 실제 장소(건물/상호)를 가리키는지 확인 필요 — 확인되는 대로
`app.js`의 `PLACE_COORDS`에 좌표 추가하거나, 자동완성 검색 시 이 은어를 실제 검색어로
치환하는 별칭 테이블을 만들면 됨.
