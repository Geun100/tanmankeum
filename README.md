# 탄만큼

**[서비스 보러가기 → tanmankeum.vercel.app](https://tanmankeum.vercel.app/)** · [랜딩페이지](https://tanmankeum.vercel.app/landing/)

같은 방향으로 가는 사람들을 "경로 기반"으로 매칭해 함께 택시를 타고 택시비를 나누는 서비스.
목적지가 같은지가 아니라 "내 목적지가 상대(팟장)의 택시 이동 경로 안에 있는가"가 매칭 기준이다. 포항에서 시작한다.

## 핵심 기능

- 출발지·목적지·시간·인원을 입력하면 경로가 겹치는 팟을 매칭 점수 순으로 추천
- 팟 상세 화면에서 내가 참가했을 때의 실제 하차 지점, 도보 시간·거리, 예상 요금을 지도로 먼저 확인
- 팟장이 직접 팟을 확정(자동 배정 없음), 확정 전 채팅방에서 조율
- 팟 요금은 실제 택시 경로 총액을 하차 지점별 주행 거리 비율로 분배 — 택시가 각자 하차지점으로 우회하지 않는다는 전제를 지킨다

## 기술 스택

- 프론트엔드: Vanilla JS 단일 페이지(`index.html`), 프레임워크 없음
- 지도·경로: 카카오맵 JS SDK, 카카오모빌리티 길찾기 API(서버 사이드 프록시로 REST 키 보호)
- 데이터: Supabase(Postgres + Realtime) — 팟/참가자/채팅
- 배포: Vercel
